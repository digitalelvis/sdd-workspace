# Integrations

## IDEs
- **VSCode**: Configuration of settings, extensions, and snippets.
- **Cursor**: Custom rules and configuration for AI features.
- **WebStorm/IntelliJ**: (Planned/Supported) configuration.

## AI Agents
- **Windsurf**: Rule and skill configuration.
- **Antigravity/Cursor**: Metadata and prompt engineering instructions.

## External Tools
- **GitHub**: Integration via `release-it` for automated releases and changelog generation.
- **NPM**: Target for package distribution.

## Workspace Ecosystems
- Supports detection and configuration for various stacks (e.g., Node.js, React, Python).
