# AI Engineering Rules

## 1. Spec-Driven Development (SDD)

For ANY new feature, issue, project initialization, or architecture documentation, your **first step** is to consult the SDD skill:

- **Path:** `.agents/skills/tlc-spec-driven/SKILL.md`

Do NOT start writing code or making architectural changes without first reading the SDD skill and creating/updating the necessary specifications (e.g., `spec.md`, `tasks.md`, `design.md`) as mandated by the skill's sizing rules.
